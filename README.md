# 異世界冒険ゲーム — フェーズ1

仕様書17章のフェーズ1だけを実装した、決定的なフルオート戦闘エンジンです。

## 実行

```bash
npm install
npm test
npm run typecheck
npm run dev
```

開発サーバーが表示したURLをスマートフォンで開くと、サンプル戦闘のスナップショットを確認できます。同じWi-Fi内の別端末から確認するときは、PCのローカルIPアドレスを使います。

## フェーズ1の範囲

- `packages/engine`: DOMやWorkersに依存しないTypeScript戦闘エンジン
- シード付き疑似乱数による決定的な戦闘
- 行動ゲージ、スキル優先度・CT、ターゲット選択
- ダメージ・回復、状態異常、バフ・デバフ、蘇生、世界ルール
- 途中経過と最終結果のスナップショット、連戦用の引き継ぎ
- Vitestによる仕様テスト
- スマホ向けの簡易スナップショット確認ページ

マスターデータ基盤、API、D1、育成、冒険、ガチャなど、フェーズ2以降の機能は含みません。
